# لندپیج هم‌ساز

لندپیج رویداد استارتاپی هم‌ساز (کوئرا × همراه اول) با تم آجرهای لگو و موشک.
فقط HTML و CSS و JS؛ هیچ سرور یا ابزار ساختی لازم نیست.

## ساختار

```
index.html            صفحه
assets/css/style.css  استایل‌ها
assets/js/main.js     انیمیشن‌ها و فرم ثبت‌نام
assets/logos/         لوگوها (hamsaz.svg موقته)
```

آجر لگو با CSS ساخته می‌شه؛ مثلاً `<span class="brick brick--red" style="--w:3"></span>`
یه آجر قرمز سه‌خاله می‌سازه (رنگ‌ها: blue, red, yellow, green, cyan, white, silver, orange).

## اجرا

کل پوشه رو روی هر هاست استاتیکی آپلود کنید. برای دیدن روی سیستم خودتون:

```bash
python3 -m http.server 5173
```

## ثبت‌نام

فرم مستقیم از مرورگر به `https://quera.org/events/api/external_register` درخواست می‌فرسته
و کاربر رو به لینکی که کوئرا برمی‌گردونه منتقل می‌کنه.
کلید API رو بالای `assets/js/main.js` توی `QUERA_API.key` بذارید.
تا وقتی خالیه، فرم در «حالت آزمایشی» کار می‌کنه و چیزی ارسال نمی‌شه.

⚠️ این حالت موقته:
- کلید توی کد سمت مرورگره و هر کسی از سورس صفحه می‌بینتش (داک کوئرا می‌گه کلید باید روی سرور بمونه).
- اگه کوئرا CORS رو برای دامنه‌ی سایت باز نکرده باشه، مرورگر درخواست رو رد می‌کنه.
