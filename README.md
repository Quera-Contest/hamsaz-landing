# لندپیج هم‌ساز

لندپیج رویداد استارتاپی هم‌ساز (کوئرا × همراه اول) با تم آجرهای لگو و موشک.
فقط HTML و CSS و JS؛ هیچ سرور یا ابزار ساختی لازم نیست.

## ساختار

```
index.html            صفحه
assets/css/style.css  استایل‌ها
assets/js/main.js     لینک‌ها، UTM و انیمیشن‌ها
assets/logos/         لوگوها (SVG؛ هم‌ساز بازسازی‌شده از پوستر، همراه اول از سایت mci.ir)
assets/fonts/         فونت ایران‌سنس X
```

آجر لگو با CSS ساخته می‌شه؛ مثلاً `<span class="brick brick--blue" style="--w:3"></span>`
یه آجر آبی سه‌خاله می‌سازه (رنگ‌ها: blue, cyan, teal, slate).

## اجرا

کل پوشه رو روی هر هاست استاتیکی آپلود کنید. برای دیدن روی سیستم خودتون:

```bash
python3 -m http.server 5173
```

## لینک‌ها و ثبت‌نام

همه‌ی دکمه‌های ثبت‌نام مستقیم به صفحه‌ی ثبت‌نام رویداد در کوئرا می‌رن.
آدرسش رو توی `LINKS.register` بالای `assets/js/main.js` بذارید؛ پارامترهای UTM (`REGISTER_UTM`) خودکار بهش اضافه می‌شن.
وقتی این لینک پر بشه، دکمه‌ی ثابت ثبت‌نام پایین صفحه هم در موبایل نمایش داده می‌شه.
بات تیم‌سازی (`@HamsazTeamBot`)، پشتیبانی تلگرام (`@quera_info`) و آیین‌نامه هم همون‌جا تنظیم می‌شن.
هر لینکی که خالی باشه با برچسب «به‌زودی» و غیرفعال نشون داده می‌شه؛ دکمه‌ی دانلود قالب معرفی‌نامه هم تا فایل واقعی نباشه فعال نمی‌شه.
بخش‌هایی از متن که هنوز نهایی نشدن با کامنت `TODO` توی `index.html` مشخص شدن.

## منبع محتوا

همه‌ی تاریخ‌ها، معیارها و قواعد صفحه از «سند طراحی و راهبری علمی رویداد» (نسخه‌ی فشرده، ۲۹ مهر ۱۴۰۵) گرفته شده.
هر تغییر تاریخ یا قاعده باید هم‌زمان در این صفحه و متن فراخوان اعمال بشه و تاریخ «آخرین به‌روزرسانی» پایین صفحه هم عوض بشه.
صفحه عمداً فقط اطلاعات لازم برای تصمیم به ثبت‌نام رو داره؛ جزئیات تخصصی (زیرحوزه‌ها، پرسش‌های معرفی‌نامه، معیارها، شرایط قبولی و اعتراض) باید در آیین‌نامه‌ی کامل (`LINKS.rules`) بیاد.

## گایدلاین کوئرا

- فونت: ایران‌سنس X (`assets/fonts`)
- رنگ برند در تم دارک: برند ۲۰۰ (`#91DEF3`) با متن `#1D2531` روی دکمه
- کنتراست متن‌ها حداقل AA؛ صفحه روی عرض ۳۶۰ پیکسل بررسی شده
