# لندپیج هم‌ساز

لندپیج رویداد استارتاپی هم‌ساز (همراه اول × کوئرا) با تم آجرهای لگو.
فقط HTML و CSS و JS؛ هیچ سرور یا ابزار ساختی لازم نیست.

## ساختار

```
index.html            صفحه
assets/css/style.css  استایل‌ها
assets/js/main.js     لینک‌ها، UTM و انیمیشن‌ها
assets/img/hero-team.webp  تصویر هیرو، بریده‌شده از پوستر رویداد
assets/logos/         لوگوها (SVG؛ هم‌ساز بازسازی‌شده از پوستر، همراه اول از سایت mci.ir؛ حامیان PNG سفید و شفاف)
assets/fonts/         فونت ایران‌سنس X
```

آجر لگو با CSS ساخته می‌شه؛ مثلاً `<span class="brick brick--blue" style="--w:3"></span>`
یه آجر آبی سه‌خاله می‌سازه (رنگ‌ها: blue, cyan, teal, slate).

## اجرا

کل پوشه رو روی هر هاست استاتیکی آپلود کنید. برای دیدن روی سیستم خودتون:

```bash
python3 -m http.server 5173
```

## لینک‌ها و ثبت‌نام

همه‌ی دکمه‌های ثبت‌نام به `https://quera.org/events/hamsaz1/register` می‌رن (توی `LINKS.register` بالای `assets/js/main.js`)
و پارامترهای UTM (`REGISTER_UTM`) خودکار بهش اضافه می‌شن.
بات تیم‌سازی (`@HamsazTeamBot`) و پشتیبانی تلگرام (`@quera_info`) هم همون‌جا تنظیم می‌شن.

## صفحه‌ی بعد از ثبت‌نام

`success.html` صفحه‌ای‌یه که کاربر بعد از ثبت‌نام در کوئرا بهش برمی‌گرده:
پیام موفقیت، زمان وبینار افتتاحیه (۲۸ آبان، ساعت ۱۶) و لینک‌های تلگرام.
آدرس: `https://hamsazplus.ir/success` (روی گیت‌هاب پیجز: `/hamsaz-landing/success.html`).

## منبع محتوا

همه‌ی تاریخ‌ها، معیارها و قواعد صفحه از «سند طراحی و راهبری علمی رویداد» (نسخه‌ی فشرده، ۲۹ مهر ۱۴۰۵) گرفته شده.
هر تغییر تاریخ یا قاعده باید هم‌زمان در این صفحه، `success.html` و متن فراخوان اعمال بشه.
صفحه عمداً فقط اطلاعات لازم برای تصمیم به ثبت‌نام رو داره؛ جزئیات تخصصی (زیرحوزه‌ها، پرسش‌های معرفی‌نامه، معیارها، شرایط قبولی و اعتراض) باید در آیین‌نامه‌ی کامل (`LINKS.rules`) بیاد.

## گایدلاین کوئرا

- فونت: ایران‌سنس X (`assets/fonts`)
- رنگ برند در تم دارک: برند ۲۰۰ (`#91DEF3`) با متن `#1D2531` روی دکمه
- کنتراست متن‌ها حداقل AA؛ صفحه روی عرض ۳۶۰ پیکسل بررسی شده
